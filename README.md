# HR-ANALYTICS-DASHBOARD
Developed an interactive HR Analytics Dashboard using Microsoft Excel to analyze employee data, gender-wise distribution, attrition, departments, and job roles. Utilized Pivot Tables, Pivot Charts, KPIs, and Slicers to visualize workforce insights and support data-driven HR decision-making.
# HR Analytics Dashboard using Microsoft Excel

## 📌 Project Overview

This project focuses on analyzing Human Resources (HR) data using Microsoft Excel to gain insights into employee demographics, workforce distribution, and employee attrition. The interactive HR Analytics Dashboard helps users understand key HR metrics through KPIs, Pivot Tables, charts, and slicers.

The dashboard provides a clear overview of employee data and supports data-driven decision-making for workforce management.

## 🎯 Project Objectives

- Analyze total employee count and gender-wise distribution.
- Understand employee attrition and retention patterns.
- Explore employee distribution across departments and job roles.
- Analyze employee satisfaction, work-life balance, and job involvement.
- Identify trends based on age groups, education, and experience.
- Create an interactive dashboard for HR reporting.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- Pivot Tables
- Pivot Charts
- Excel Slicers
- KPIs and Data Visualization
- Excel Data Analysis

## 📊 Key Dashboard Features

- **Total Employees:** Overview of the workforce.
- **Gender Analysis:** Male and female employee distribution.
- **Employee Attrition:** Analysis of employees who left the organization.
- **Department Analysis:** Employee distribution across departments.
- **Job Role Analysis:** Workforce distribution by job roles.
- **Age Group Analysis:** Employee demographics by age bands.
- **Employee Satisfaction:** Insights into job satisfaction and work-life balance.
- **Interactive Filters:** Slicers to explore data dynamically.

## 🔍 Key Insights

The dashboard helps explore questions such as:

- How many employees work in the organization?
- What is the gender-wise employee distribution?
- Which departments have higher employee attrition?
- Which job roles have the highest number of employees?
- How does attrition vary across age groups?
- What patterns can be observed in employee satisfaction and experience?
